# AoC: Advent of Code

Each year, since 2015, in December, [Eric Wastl](https://was.tl/) publishes the
[Advent of Code](https://adventofcode.com/), an advent calendar of of programming puzzles.

The last few years, I participated in this challenge, and enjoyed solving those programming
headache. Since my time is always limited during this busy last month of the year and the puzzles
are increasingly difficult, I only ever solved the first few days.

You can find below the summary of my former attempts:
